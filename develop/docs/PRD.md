# Meeting Assistant AI

## Versión
0.2.0-alpha

## Objetivo

Desarrollar una aplicación de escritorio para Windows capaz de capturar el audio de reuniones (Microsoft Teams, Google Meet, Zoom u otras plataformas), transcribirlas localmente mediante IA y generar automáticamente una minuta profesional en formato Microsoft Word.

## Objetivos específicos

- Capturar audio del sistema y micrófono.
- Transcribir en tiempo real.
- Identificar acuerdos.
- Detectar tareas.
- Detectar responsables.
- Detectar fechas compromiso.
- Generar minutas profesionales.
- Mantener historial de reuniones.

## Tecnologías

- Python
- CustomTkinter
- Whisper.cpp
- Ollama
- python-docx

## Restricciones

- Todo debe funcionar localmente.
- No utilizar APIs de pago.
- Compatible con Windows 11.
- Consumo moderado de recursos.

## MVP

- Iniciar reunión.
- Detener reunión.
- Capturar audio.
- Transcribir.
- Generar Word.
