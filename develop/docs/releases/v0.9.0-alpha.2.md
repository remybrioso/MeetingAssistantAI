# Meeting Assistant AI v0.9.0-alpha.2

## Tipo de release

Alpha de distribución para Windows.

Esta release consolida el AI Pipeline de `v0.9.0-alpha.1` y añade el trabajo necesario para instalar y preparar MAI en un equipo Windows sin requerir un entorno Python del usuario.

## Highlights

### Aplicación instalable

- Ejecutable PyInstaller one-folder.
- GUI productiva sin consola.
- Instalador Inno Setup.
- Instalación por usuario.
- Accesos directos de Windows.
- Desinstalador.

### First-run guiado

El Setup Wizard comprueba:

- recursos internos;
- workspace;
- transcripción;
- IA;
- audio.

### Transcripción

Cuando el modelo de Faster-Whisper no está disponible:

```text
Descargar modelo
```

El usuario inicia explícitamente la descarga y MAI vuelve a verificar el estado al terminar.

### Ollama

Cuando Ollama no está disponible:

```text
Abrir descarga de Ollama
```

MAI abre la fuente oficial y espera la intervención del usuario.

Cuando Ollama está disponible pero falta el modelo:

```text
Descargar modelo de IA
```

MAI utiliza la API local de Ollama para descargar:

```text
qwen2.5:3b
```

y comprueba que el modelo quede disponible antes de dar la reparación por terminada.

### Audio

MAI detecta micrófono y captura loopback del sistema.

Cuando Windows requiere configuración manual, MAI abre la configuración nativa de sonido y utiliza un estado de `Acción requerida` en lugar de declarar falsamente que el problema fue resuelto.

La ausencia de loopback puede quedar en estado degradado sin bloquear la aplicación si el micrófono sigue disponible.

## Meeting Intelligence

La release mantiene el pipeline staged de la línea 0.9:

- clasificación por chunks;
- enriquecimiento de acciones;
- consolidación global;
- validación grounded;
- `MeetingReport`;
- acciones y decisiones deterministas;
- entrega Markdown, DOCX y PDF.

## Requisitos de usuario

- Windows 10/11 x64.
- Micrófono utilizable para captura en vivo.
- Ollama para las funciones de IA.
- Internet durante la preparación inicial de dependencias/modelos.

## Limitaciones conocidas

- Release alpha.
- Windows únicamente en esta etapa.
- Instalador sin firma digital.
- Sin actualización automática.
- Ollama se instala como aplicación externa.
- El audio del sistema depende de loopback compatible en Windows.
- Las primeras descargas de modelos pueden ser grandes.

## Integridad del artefacto

La GitHub Release debe publicar el SHA256 exacto de:

```text
MeetingAssistantAI-Setup-v0.9.0-alpha.2.exe
```

El hash se calcula después de generar y validar el artefacto final de esta versión.
