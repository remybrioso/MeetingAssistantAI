# DOC-002 - Instalación desde el repositorio

## Versión

v0.9.2-alpha.1

## Objetivo

Documentar el procedimiento completo para clonar, configurar, validar y ejecutar MAI desde el código fuente.

## Archivos

- docs/INSTALLATION_FROM_SOURCE.md
- README.md
- requirements.txt
- requirements-lock.txt

## Criterios de aceptación

- Un colaborador puede preparar MAI desde un repositorio limpio.
- Se documenta la creación del entorno virtual.
- Se documentan las dependencias Python.
- Se documentan Ollama y el modelo requerido.
- Se incluyen pruebas de diagnóstico.
- Se documenta la configuración de audio.
- Se distinguen claramente el entorno de desarrollo y el instalador final.
