# MAI-015 - Integración de captura dual

## Estado

En progreso

## Feature

002 - Dual Audio Capture

## Objetivo de negocio

Cada reunión almacenará por separado el audio del micrófono y el audio del sistema.

## Objetivo técnico

AudioCaptureService coordinará ambos motores de captura.

## Archivos afectados

### Modificar

- services/audio_capture_service.py

## Criterio de aceptación

- Se crea una RecordingSession.
- Se inicia MicrophoneEngine.
- Se inicia SystemAudioEngine.
- Ambos trabajan sobre la misma sesión.
- La aplicación continúa funcionando.
