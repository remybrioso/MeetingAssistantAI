# AI-011B - Importación WAV desde la GUI

## Versión

v0.9.1-alpha.1

## Objetivo

Permitir seleccionar y procesar una grabación WAV desde la interfaz de MAI.

## Archivos afectados

- application/app_controller.py
- gui/components/action_panel.py

## Criterios de aceptación

- Existe el botón Importar grabación.
- Solo permite seleccionar archivos WAV.
- El procesamiento ocurre en segundo plano.
- No se puede importar mientras existe una reunión activa.
- La interfaz no se bloquea.
- Se muestran mensajes de inicio, finalización y error.
- Se crea un Workspace completo para la reunión importada.
