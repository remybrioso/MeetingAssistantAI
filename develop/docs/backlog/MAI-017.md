# MAI-017 - Redefinir roadmap hacia Transcript Pipeline

## Estado
En progreso

## Feature
003 - Transcript Pipeline

## Objetivo de negocio
Mejorar la calidad de transcripción manteniendo separados el audio local y el audio remoto.

## Decisión técnica
No se mezclará audio antes de transcribir.

Se transcribirá por separado:

- mic.wav
- system.wav

Luego se fusionarán las transcripciones por timestamps.

## Resultado esperado
- Mejor separación entre participante local y remoto.
- Menos solapamiento de voces.
- Preparación para identificar interlocutores.
