# MAI-001 - Definir metodología de trabajo

## Estado
En progreso

## Objetivo
Establecer una metodología clara para desarrollar Meeting Assistant AI por historias pequeñas, probadas y versionadas.

## Reglas
- Cada historia debe indicar archivos a crear, modificar o eliminar.
- Cada historia debe tener prueba de aceptación.
- No se avanza si hay errores.
- Cada historia aprobada debe tener commit.
- La rama `develop` será usada para desarrollo.
- La rama `main` solo recibirá versiones estables.

## Criterio de aceptación
- Estructura de backlog creada.
- Bitácora actualizada.
- Convención de commits definida.
