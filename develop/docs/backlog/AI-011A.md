# AI-011A - Importación WAV

## Versión

v0.9.1-alpha.1

## Objetivo

Procesar una reunión existente en formato WAV mediante el pipeline actual de MAI.

## Flujo

1. Validar el WAV.
2. Crear MeetingWorkspace.
3. Copiar como Audio/Reunion.wav.
4. Transcribir.
5. Guardar transcript y métricas.
6. Generar Summary.
7. Exportar Documentos/Resumen.md.

## Archivos afectados

- models/recording_session.py
- services/imported_meeting_service.py
- tests/test_imported_meeting_service.py

## Criterios de aceptación

- Se acepta un WAV válido.
- Se rechazan archivos inexistentes o con otra extensión.
- Se crea un Workspace independiente.
- Se genera transcript.json.
- Se genera processing_metrics.json.
- Se genera summary.json.
- Se genera Resumen.md.
- No se modifica el archivo original.
