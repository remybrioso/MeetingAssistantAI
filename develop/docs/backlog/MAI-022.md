# MAI-022 - WhisperConfiguration

## Estado
En progreso

## Feature
003 - Transcript Pipeline

## Objetivo de negocio
Permitir configurar el motor de transcripción sin modificar código.

## Objetivo técnico
Crear un objeto de configuración para Whisper.

## Archivos afectados

### Crear
- providers/whisper/whisper_configuration.py
- tests/test_whisper_configuration.py

## Riesgos
- El modelo configurado podría no existir.
- El idioma configurado podría no estar soportado.
- El dispositivo seleccionado podría no estar disponible.

## Criterio de aceptación
- Existe una configuración por defecto.
- El idioma por defecto es español.
- El dispositivo por defecto es CPU.
- El modelo por defecto es base.
